# design-system

Sistema de operación de Servicio: caja, comanda, autopago, runners, fundamentos y componentes.

```bash
npm install
npm run dev
```

La aplicación abre en `/`. Las secciones se eligen con `?vista=` (`fundamentos`, `componentes`, `caja`, `comanda`, `autopago`, `runners`). El estado de pedidos es compartido entre caja, comanda, autopago y runners.
